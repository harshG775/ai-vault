## Reference precedence

1. Approved front portrait controls the canonical face.
2. Approved three-quarter portrait controls angled facial geometry.
3. Approved profile controls the side silhouette.
4. Full-body reference controls overall proportions.

## Approval criteria

- Same facial structure across views
- Stable eye color and spacing
- Stable nose and lip shape
- Stable hairline and hair color
- Distinctive features in the correct positions
- No unexplained changes to body proportions
